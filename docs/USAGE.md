# 使用手册

## 0. 界面分区

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：截取窗口 / 整屏 / 历史 │ 选择 框选 挪动 │ 撤销 删除 适应 1:1 叠加层 │ 复制指令 数据目录 MCP状态 │
├───────────────────────────────┬──────────────────────────────┤
│                               │  提示词 / 标注                 │
│        图片区域                │  ├ 会话信息（来源窗口、尺寸）    │
│  （截图 + 叠加层 + 状态栏）      │  ├ 标注卡片列表（提示词输入）    │
│                               │  └ 底部：保存状态 / 计数 / 批量操作│
└───────────────────────────────┴──────────────────────────────┘
```

- **图片区域**：左键拖 = 按当前工具操作；滚轮缩放；空白处拖 = 平移。
- **提示词区域**：每条标注一张卡片；卡片上的编号与图片里的数字徽标一一对应。

## 1. 截取

### 截取某个窗口
1. 点「截取窗口」（或 `Ctrl + N`）。
2. 列表按「是否在前台 / 是否最小化 / 进程名」排序；可在过滤框输入标题或进程名（如 `godot`、`unity`）。
3. 单击目标窗口即开始截取。窗口会被短暂切到前台，截图完成后应用自动回到前台。

### 截取整屏
点「整屏」直接抓主显示器。适合跨窗口、多窗口对照的场景。

> 如果弹出的提示条写着「目标窗口未能切到前台」，说明截图可能含遮挡，建议先把目标窗口拖到前面再截一次。

## 2. 框选 + 提示词（本软件的核心）

1. 按 `B` 或用工具栏「框选」。
2. 在图片区拖出一个矩形（不小于 5×5 像素）。
3. 松手后：图片上出现带编号的框，**右侧自动生成一条提示词条目并自动聚焦输入框**。
4. 写清楚要改成什么样。写提示词的建议：
   - 说「结果」而不是「过程」：`改成深色卡片、宽度 320、圆角 8` 比 `调一下` 有用一百倍；
   - 需要精确值时直接给：颜色、间距、字号、锚点（如 `锚点改到底部居中`）；
   - 一条标注只讲一件事，别把三个改动塞进一条。
5. `Ctrl + Enter` 保存（其实输入后 0.4 秒会自动保存，`Ctrl+Enter` 只是让你放心）。
6. 微调位置：选中后按方向键 1px / `Shift+方向键` 10px；拖控制点改大小；`Delete` 删除。

## 3. 截取区块并挪动（表达「位置错了」）

1. 按 `M` 或用「挪动」。
2. 在要挪的东西上拖出矩形，**松开鼠标**。
3. 此时区块跟着光标走（源位置留虚线框）：移动到目标位置，**单击一次**确认。
4. 记录内容：源区域 `(x,y,w,h)`、目标左上角 `(x,y)`、位移 `dx/dy`。图上一根箭头从源指向目标，目标处还有挪动后的预览。
5. 同样会生成一条提示词条目，补一句说明（如「标题栏应该贴在顶部居中，现在浮在中间」）。
6. 按 `Esc` 可随时取消正在放置的挪动。

> 拖回原位（位移 < 3px）会被视为「没挪」，不会生成无效标注。

## 4. 让 AI 落地

- **MCP 方式（推荐）**：AI 直接调用 `get_instructions` 拿到坐标与提示词，调用 `get_capture_image` 拿到叠加图；
  改完一处调 `ack_instruction`，你的界面会在 3 秒内把该条变绿并显示 AI 的备注。
- **文字方式**：点「复制指令」，会复制包含会话 ID、每条坐标、提示词和图片绝对路径的 Markdown，粘给任何 AI 都能用。
- 若 AI 说「看不到图」，让它调 `get_capture_image`（返回的就是 `annotated.png`）；AI 需要局部细节时让它调 `get_region_image`。

## 5. 状态与批量操作

| 元素 | 含义 |
| --- | --- |
| 右上角 `MCP 就绪 · 端口` | 本地桥接已启动，AI 可以连 |
| 卡片底部「待处理 / 已完成 / 已跳过」 | 该条标注的处理状态（由 AI 回写） |
| 「全部置为待处理」 | 清空所有 AI 回写状态，重新来过 |
| 「标记会话完成」 | 把整个会话标成 done（仅状态标记） |
| 底部「已保存 · 时间」 | 最近一次落盘时间；红色表示保存失败（会弹出原因） |
| 数字徽标 | 图片里的编号 = 卡片编号，AI 靠它对齐「哪条指令对应哪块区域」 |

## 6. 历史会话

点「历史」：按时间倒序列出所有截图会话，显示来源窗口、尺寸、标注数与待处理数。
单击打开，`✕` 删除（同时删掉该会话的图片与文档，不可恢复）。

## 7. 排查

| 现象 | 处理 |
| --- | --- |
| 双击快捷方式「没反应」 | 已有一个实例在跑（最小化或被挡住）：会弹「已在运行」提示框并把窗口切到前台 |
| 窗口列表是空的 | 目标窗口可能最小化到托盘或没显示过；把它点出来再点「刷新」 |
| 截出来的图是黑的/别人的窗口 | 前台切换被系统拦了；看提示条，先把目标窗口拉到前面 |
| MCP 显示「未启动」 | 应用正常启动才有桥接；看 `data/app.log` |
| AI 读到的标注是旧的 | 看右下角「已保存」时间；`Ctrl+S` 强制保存一次 |
| 叠加图和实际框选不一致 | 界面渲染后自动回存，稍等 1~2 秒；或改一下任一提示词触发重存 |

## 8. 一键让 AI 开始修改

1. 先框选/挪动并把提示词写清楚（提示词为空的条目会被 AI 跳过）。
2. 点提示词区底部的 **「让 AI 开始修改」**。
3. 弹窗会**自动填好**：
   - **投递方式**：默认「投递到选中的 DSH 对话并自动开始」（官方接口，已验证会真的执行）。
   - **工作区**：你最近活跃的那个工程目录。
   - **对话**：**你界面上正打开的那条对话**（按 DSH 窗口标题里的对话名匹配得出）。
   - **发给 AI 的指令**：可改。
4. 点「投递并开始」。这条消息会作为一条用户消息出现在那条对话里，DSH 立刻开始这一轮，
   你会直接看到它在调用 `get_instructions` / `get_region_image` / godot-ai 的工具。卡片状态也会随之变绿。

其它按钮/选项：

- **＋ 新建对话**：在所选工作区新建一条对话再投递。新建的对话在 DSH 侧边栏可能要点一下或按 F5 才出现，
  所以默认不选它。
- **打开 DSH**：在浏览器里打开 DSH 界面（端口自动探测）。
- **备用：粘贴到 DSH 窗口**：模拟 Ctrl+V + 回车，需要 DSH 输入框已聚焦。
- **后台任务（headless）**：不打开 DSH，后台跑，进度显示在左下角。

> 弹窗顶部会显示 `DSH 接口已连接（端口 3080，N 个对话）`；若显示未连接，说明 DSH 没在跑或凭证失效，
> 可切「备用：粘贴」方式。
